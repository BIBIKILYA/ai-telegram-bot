#  Мультимодальный AI-ассистент в Telegram

Это Telegram-бот, который понимает текст, голос и изображения. Он отвечает на вопросы и может собрать по запросу готовую презентацию (`.pptx`) или структурированный доклад (`.docx`). 

Проект написан как демонстрация навыков работы с LLM, оркестрации процессов и связки no-code (n8n) с кастомным бэкендом.

---

## Стек и почему я его выбрал

- **n8n** — оркестратор всей логики. Я выбрал его, чтобы попрактиковаться в разработке ИИ-агентов и не писать тонны шаблонного кода для роутинга сообщений и работы с файлами.
- **YandexGPT-5-Pro** — основная языковая модель. Отлично справляется с русским языком, поддерживает вызов инструментов (Tools) и имеет адекватный API.
- **Google Gemini (Flash)** — используется только для работы с изображениями (распознавание текста и кода на скриншотах, описание визуального контекста).
- **Yandex SpeechKit** — для распознавания голосовых сообщений. Лучшее качество транскрибации русской речи.
- **Tavily API** — инструмент для поиска в интернете. Подключен к агенту, чтобы он не выдумывал факты, а брал актуальные данные о версиях библиотек, новостях или документации.
- **Python (http.server + python-pptx/python-docx)** — кастомный микросервис. n8n не умеет верстать сложные документы из коробки, поэтому я написал свой скрипт. Он принимает структурированный JSON от нейросети и собирает из него реальный файл.

---

##  Что умеет бот

1. **Работает с голосом:** Расшифровывает голосовые сообщения и отвечает по существу. Если распознавание не удалось (например, из-за невнятного бормотания), вежливо просит написать текст.
2. **Анализирует фото:** 
   - Если на фото код — выписывает его, находит ошибки и объясняет, как их исправить.
   - Если на фото текст — распознает его дословно.
   - Если на фото объект/место — описывает его и может найти информацию о нем через поиск.
3. **Генерирует файлы:** По запросам вроде «сделай презентацию про космос» или «напиши доклад по истории» бот формирует строгий JSON, передает его в Python-скрипт и присылает готовый файл в формате `.pptx` или `.docx`.
4. **Не молчит при сбоях:** Если упал SpeechKit, закончились токены или недоступен Python-скрипт, бот не зависает, а честно сообщает об ошибке и просит повторить запрос позже.

##  Как запустить у себя

### 1. Предварительная подготовка
Убедись, что предварительно установлены Node.js и Python.
bash
Устанавливаем n8n глобально
npm install -g n8n
Устанавливаем библиотеки для генерации файлов
pip install python-pptx python-docx


### 2. Настройка переменных окружения
Создаем файл `.env` в корневой папке на основе `.env.example`. Ключи необходимо заменить на свои:

```env
TG_BOT_TOKEN=твой_токен_телеграма
YC_API_KEY=твой_ключ_яндекса
YANDEX_FOLDER_ID=твой_id_папки_яндекса
TAVILY_API_KEY=твой_ключ_tavily

# Адрес локального Python-скрипта
FILE_GENERATOR_URL=http://127.0.0.1:8888
PRESENTATION_OUTPUT_DIR=C:\n8n-output\presentation
WORD_OUTPUT_DIR=C:\n8n-output\word

# Разрешаем n8n читать переменные окружения в Code-нодах
N8N_BLOCK_ENV_ACCESS_IN_NODE=false
```
Создаем папки для вывода файлов, указанные в путях (например, C:\n8n-output\presentation), чтобы скрипту было куда сохранять результат.
### 3. Запуск
Используем два окна терминала.
В первом запускаем генератор файлов:

cd python-generator
python server.py

Во втором запускаем n8n (из папки, где лежит .env):
n8n start

### 4. Импорт в n8n

В браузере открываем http://localhost:5678, переходим в Workflows → Import from File и выбираем workflow.json из этого репозитория.
(Важно: n8n не переносит секреты при импорте, нужно будет вручную создать и привязать Credentials для Telegram, YandexGPT, Google Gemini и Tavily).

## Особенности реализации
-  Модульные промпты: Вместо одного гигантского промпта, который путает модель, я использую Code-ноду Load prompt. Она определяет тип запроса (фото/голос/текст/презентация) и подставляет только нужную, короткую инструкцию. Это экономит токены и делает ответы точнее.
- Надежный парсинг JSON: Нейросети часто любят добавлять фразы вроде "Вот ваш JSON:" перед данными. Мой парсер сначала ищет блоки ````json, а если их нет — вырезает всё, что находится между первой{и последней}`, игнорируя лишний текст.
- Безопасность: В коде нет захардкоженных токенов, ID папок или локальных путей. Всё вынесено в $env, что позволяет легко перенести проект на сервер или в Docker.
- Обработка ошибок: На критических нодах (SpeechKit, Gemini, AI Agent, генератор файлов) включен On Error → Continue, который перенаправляет поток в Telegram-уведомление об ошибке, чтобы бот не "умирал" молча.
