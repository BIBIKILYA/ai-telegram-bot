# ai-telegram-bot
Это Telegram-бот, который понимает текст, голос и изображения. Он отвечает на вопросы и может собрать по запросу готовую презентацию (.pptx) или структурированный доклад (.docx).
Проект написан как демонстрация навыков работы с LLM, оркестрации процессов и связки no-code (n8n) с кастомным бэкендом.


Стек и почему я это выбрал:

n8n — оркестратор всей логики. Выбрал его чтобы попрактиковаться на разработке ИИ-агентов
YandexGPT-5-Pro — основная языковая модель. Отлично справляется с русским языком, поддерживает вызов инструментов (Tools) и имеет адекватный API.
Google Gemini (Flash) — используется только для работы с изображениями (распознавание текста и кода на скриншотах и описания визуального контекста).
Yandex SpeechKit — для распознавания голосовых сообщений.
Tavily API — инструмент для поиска в интернете. Подключен к агенту, чтобы он не выдумывал факты, а брал актуальные данные о версиях библиотек, новостях или документации.
Python (http.server + python-pptx/python-docx) — кастомный микросервис. n8n не умеет верстать сложные документы из коробки, поэтому я написал свой скрипт с помощью ИИ. Он принимает структурированный JSON от нейросети и собирает из него реальный файл.

Что умеет бот:

Работает с голосом: расшифровывает голосовые сообщения и отвечает на них по сути. Если распознавание не удалось (например, бормотание), вежливо просит написать текстом.
Анализирует фото:
Если на фото код — выписывает его, находит ошибки и объясняет, как исправить.
Если на фото текст — распознает его дословно.
Если на фото объект/место — описывает его и может найти информацию о нем через поиск.
Генерирует файлы: По запросам вроде "сделай презентацию про космос" или "напиши доклад по истории" бот формирует строгий JSON, передает его в Python-скрипт и присылает готовый .pptx или .docx файл.
Не молчит при сбоях: Если упал SpeechKit, закончились токены или Python-скрипт недоступен, бот не зависает, а честно сообщает об ошибке и просит повторить позже.

Как запустить у себя: 

1. Предварительно установить Node.js и Python
2. Устанавливаем n8n глобально
npm install -g n8n
3. Устанавливаем библиотеки для генерации файлов
pip install python-pptx python-docx
4. Создаем файл .env в корне папки  на основе .env.example. Ключи необходимо заменить на свои 
TG\_BOT\_TOKEN=твой\_токен\_телеграма
YC\_API\_KEY=твой\_ключ\_яндекса
YANDEX\_FOLDER\_ID=твой\_id\_папки\_яндекса
TAVILY\_API\_KEY=твой\_ключ\_tavily
\# Адрес локального Python-скрипта
FILE\_GENERATOR\_URL=http://127.0.0.1:8888
\# Разрешаем n8n читать переменные окружения в Code-нодах
N8N\_BLOCK\_ENV\_ACCESS\_IN\_NODE=false

5. Создаем папки для вывода файлов, указанные в путях (например, C:\\n8n-output\\presentation), чтобы скрипту было куда сохранять результат.
6. Запуск
Используем два окна терминала.
В первом запускаем генератор файлов: 
cd python-generator
python server.py
Во втором запускаем n8n (из папки, где лежит .env):
n8n start
7. В браузере открываем http://localhost:5678
